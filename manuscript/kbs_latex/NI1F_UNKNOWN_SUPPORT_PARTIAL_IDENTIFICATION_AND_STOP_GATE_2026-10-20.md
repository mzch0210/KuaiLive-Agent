# N12-NI / NI-1f — 未知真实支持集的有限库部分识别、有限样本与停止门

**2026-10-20；NI-1f 公开合成分析与本地测试完成；GitHub CI 结果须独立核查；M3 corrected-S 方法学批准仍为 HOLD。**

## 研究动机和严谨范围
承接 NI-1e“准确已知四个完整 rank/overlap 原子才能训练S-only EM”的强条件，本次改为事先定义十六种完整(Base rank, Memory rank, 领先候选身份交集)潜在状态组成候选**库**，估计器不被告知生成者实际混合的四种状态。库内状态包括原四状态和十二个预定义替代状态。严格使用同一574个负例抽样的多元超几何离散观测分布(0..9及>=10删失)；禁止用F标签、真实TEST或私有DEV训练。

这**不是完全未知支持集的非参数识别**：估计者仍由实验设计者事前获得16个可能状态及其完整rank，这是强辅助信息。这里计算的是**此有限库内**给定观测概率TV半径的最小/最大 full conditional Δ，库外分布不在保证范围内。

## 方法与程序
生成真值使用NI-1e现有相同两组，N=14022、53762；各自前4原子及固定混合权重，仅用于生成合成的sampled joint-label概率，估计器使用全部16原子。令 E_N 是121种理论采样联合类别的 emission matrix，v是原子的full Memory−Base NDCG10，p是生成世界的采样分布。求线性规划:
```
min/max v'w   s.t. w>=0, 1'w=1, 0.5*||E_N w-p||_1 <= epsilon
```
LP给定有限库及TV tolerance场景的sharp envelope；epsilon是**自选的敏感性参数，不是经验置信区间**。epsilon=1e-7用来规避浮点LP算法在0精确等式上的容差/不可行问题，不能被称作严格精确识别。额外通过模拟从同一个p随机抽取500、2000、20000、50000个synthetic joint outcomes（每档20次）来展示样本TV波动；并不据此得出有效总体CI。

## 识别与创新性裁决

1. **正面**：在给定正确且已知的16状态库、近乎精确的总体采样分布时，full Δ能被局部约束很窄，纯粹“不可识别”并非适用于所有结构模型。
2. **负面**：允许非常小的采样分布TV偏离，full Δ的可行范围迅速变宽；N=53762的TV=.01甚至包含0，策略是否调用可以变得不可判定。这是有限库敏感性，不是无假设总体下界。
3. **有限样本**：观察噪声在一些现实规模档位已超过用于窄区间解释的epsilon，单凭heldout sampled-likelihood表现不错，不足以推出full条件价值已经识别。
4. **最近邻**：KDD2020 Krichene/Rendle采样指标偏差、AAAI2021 Jin等rank-distribution推断、AAAI2023 Li等“Towards Reliable Item Sampling for Recommendation Evaluation”信息盲区形成直接先例。本LP只是把已知inverse-problem/partial-identification形式应用于单正例shared-negative joint labels的公开toy，不宣称新的通用理论或算法。
5. **当前论文不改**：NI-1f没有证明实际M3的full条件值无法识别，也没有验证新的合法corrected-S selector，既有RQ2仅限F相对原未校正S。不得以toy LP取代同预算真实政策与独立新数据。
