\title{Candidate-Aligned Knowledge Valuation for Selective Relationship Memory Routing in Live-Streaming Recommendation}

\author{Anonymous Authors}

\begin{abstract}
A historical relationship ranker may help a live-streaming recommender only on some requests, and its measured gain over a fixed incumbent depends on the available candidates. We examine whether the candidate regime used to supervise that relative value changes the resulting frozen knowledge-use policies. Sampled-active and full-active NDCG@10 increments supply labels for separately fitted selectors using the same pretarget features and fixed Base/Memory pair; both policies are evaluated on identical full-active candidates. In a retrospective paired comparison of 10,222 KuaiLive room-ranking events, Memory-minus-Base value changes from $-0.04120$ under sampled-active candidates to $+0.04631$ under full-active candidates. The primary evaluation uses 30,000 additional M3 author-ranking targets from the same recording period. Relative to the original uncorrected sampled-label policies, full-candidate-supervised policies increase weighted full-candidate NDCG@10 by $0.005391$ for SASRec and $0.003585$ for GRU4Rec, with lower population-weighted Memory-call fractions under naturally realized policies. A shared 50,049-request DEV analysis finds different invocation decisions on 21.32\% and 23.01\% of requests, respectively. These observations compare complete, separately calibrated frozen policies with unequal call rates; they do not identify an equal-resource label-only causal effect or demonstrate deployment cost savings. The findings position candidate alignment as a consequential part of the supervision contract for selective use of fixed historical knowledge.
\end{abstract}

\section{Introduction}

Live-streaming recommenders rank choices that change as broadcasts begin and end, while viewer--creator relationships accumulate across sessions. A sequential incumbent can already represent part of that history; a separate relationship-memory ranker may add useful information on some requests but offer no advantage on others. For a knowledge-based decision system, the practical question is therefore not simply whether historical knowledge is predictive, but whether using a fixed additional source improves the ranking over the incumbent \emph{for the candidates currently available}.

Learning to defer and selective inference provide established approaches to choosing between predictors \cite{mozannar2020defer,mao2024regression}. Such a choice requires a supervision target. We consider the observed NDCG@10 increment of a fixed Memory ranking over a fixed Base ranking. When the same target is scored against 575 sampled-active candidates instead of all eligible candidates, that increment can change. Sampled ranking metrics are already known to distort full-ranking comparisons \cite{krichene2020kdd}; our question is narrower and downstream: \emph{does the candidate regime used to construct relative-value labels change the requests selected for historical Memory and the full-candidate outcomes of the resulting policies?}

We evaluate this question without proposing a new Memory representation or a new generic routing algorithm. Two pretarget selection policies share the same incumbent, Memory scorer and full-candidate decision features, but learn from sampled-active or full-active relative-value labels. Each policy is separately fitted and development-calibrated before evaluation on identical full-active candidate sets. The primary evidence comprises 30,000 additional M3 author-ranking targets from the same recorded TEST-source period, not a new chronological or user-disjoint replication. A previously evaluated paired room-ranking cohort motivates the label distinction; a separate DEV decision trace characterizes allocation changes without serving as an independent held-out test.

The design supports two connected empirical contributions:
\begin{itemize}
    \item \textbf{Candidate-regime sensitivity of the supervision target.} In paired room-ranking events with the same frozen rankers, moving from sampled-active to full-active candidates changes the measured Memory-minus-Base utility, motivating candidate-aware labels. This is a diagnostic of the evaluation contract, not an isolated candidate-count effect.
    \item \textbf{Frozen policy consequences.} On additional M3 author-ranking events, F-supervised policies improve population-weighted full-candidate NDCG@10 and have lower realized weighted Memory-call fractions than policies trained with the original, uncorrected sampled labels. DEV request-level allocation differences describe fitted decisions, not causal mediation of the additional-target result.
\end{itemize}

The scientific boundary is part of the question. The two frozen policies realize different call rates and the sampled comparator has no evaluated statistically corrected counterpart; the contrast is not an experimentally isolated equal-resource label effect. Unconditional Memory can rank better when invocation is unrestricted, and lower call fractions do not establish production latency savings. Sections~\ref{sec:framework}--\ref{sec:results} define, test and interpret the candidate-aligned supervision contract while preserving those limitations.

\section{Related Work}

\subsection{Relationship Knowledge and Decisions to Use It}

Knowledge-aware and sequential recommenders investigate how historical interactions and relational evidence enter a ranking model \cite{kang2018sasrec,chen2024cklf,xie2026mhgfcl,kim2026kaper}. Other work studies which user information should be retained or organized for later prediction \cite{zhong2026samd,chen2026memrec}. These questions concern representation or storage. In contrast, we hold the historical Short--Long--Popularity Memory scorer fixed and study the \emph{use-time decision} to replace an incumbent ranking with its ranking on an available candidate roster.

Learning-to-defer and adaptive inference already formalize selection among predictors, including relative loss and instance-dependent costs \cite{mozannar2020defer,narasimhan2022posthoc,mao2024regression,yuan2026dsframe}. Decision-focused learning further explains why surrogate prediction quality need not match downstream decision quality \cite{mandi2024decisionfocused}. Our experiments do not claim a new consistency theorem, deferral architecture or gate optimizer. They ask what happens when the \emph{labels supervising a fixed specialist's relative value} are computed in a candidate regime different from the one used for ranking.

\subsection{Sampled Ranking and Candidate-Regime Alignment}

LiveRec and KuaiLive provide examples of time-varying broadcast eligibility and persistent viewer--creator histories, although streamer, room and author ranking are distinct tasks \cite{rappaz2021liverec,qu2026kuailive}. Candidate sampling in large-scale recommendation is not a neutral evaluation shortcut: sampled ranking metrics may fail to preserve the ordering of methods under exact full-catalog metrics \cite{krichene2020kdd}. Rank-estimation and sampling-correction methods seek more reliable full-ranking estimates or training losses \cite{jin2021sampledeval,li2023reliable,li2024itemsampling,subbiah2024rankestimation}. Logged exposure adds a further constraint on what observed positive interactions can establish \cite{pereira2025samplingreliability}.

That literature establishes the possibility of sampled/full ranking disagreement; it does not by itself provide this study's frozen downstream knowledge-use comparison. Here sampled evaluation generates a target for the \emph{incremental benefit of invoking Memory over Base}. The consequent fitted policies are then compared on the same full-active candidates. The tested sampled-label arm uses the original, uncorrected target-retained protocol; a valid corrected sampled-only policy could narrow the observed difference and has not been evaluated. The study's contribution is therefore a bounded empirical decision consequence, not a general proof that full-candidate labels dominate every corrected sampling approach.

\section{Candidate-Aligned Knowledge-Use Supervision}
\label{sec:problem}
\label{sec:framework}

We examine one decision: given a trained incumbent ranker and a fixed historical relationship specialist, should the system use the specialist for the current eligible candidates? The central object is \emph{incumbent-relative ranking value}, measured with the candidate roster actually evaluated. Only the predicted value and pretarget observations enter the learned invocation decision; target-dependent ranking labels are used offline.

\subsection{Ranking Events and Candidate-Dependent Value}
\label{sec:event-utility}

Let $\xi_r=(u,t,\mathcal{C}^{(r)}_{u,t},\mathcal{H}_{u,t})$ denote user $u$, decision time $t$, an eligible candidate roster under regime $r$, and interactions strictly preceding $t$. After observing the target $y$, the offline evaluation event is $x_r=(\xi_r,y)$. For a ranker $A$ returning a target position $r_A(y\mid\xi)$, we use one-positive NDCG@$K$:
\begin{equation}
    u_K(A,x)=
    \begin{cases}
        \displaystyle \frac{1}{\log_2\!\left(r_A(y\mid\xi)+1\right)}, & r_A(y\mid\xi)\le K,\\[6pt]
        0, & r_A(y\mid\xi)>K.
    \end{cases}
    \label{eq:event-ndcg}
\end{equation}
We set $K=10$. The same ranker may obtain different NDCG on sampled-active $S$ versus full-active $F$ alternatives because eligible identities and their competition differ; this by itself is not evidence of a change in the ranker's parameters.

\subsection{Fixed Base and Historical Relationship Memory}
\label{sec:framework-base}
\label{sec:framework-memory}

The trained Base $B$ is fixed within each comparison. The original KuaiLive \emph{room}-ranking diagnostic uses a fixed dual-identity SASRec fusion, while the primary M3 \emph{author}-ranking policy study uses separately fixed SASRec or GRU4Rec incumbents. These are different tasks and not replications of one ranking unit. The deterministic Memory ranker $M$ is an unchanged combination of previous viewer--creator interaction recency, historical repetition, and TRAIN-only author popularity:
\begin{equation}
s_M(u,i,t)=
0.45\,\mathrm{Short}(u,i,t)
+0.45\,\mathrm{Long}(u,i,t)
+0.10\,\mathrm{Pop}(i).
\label{eq:memory-scoring}
\end{equation}
Here $\mathrm{Short}$ assigns $\exp(-d/3)$ to the most recent occurrence among the previous ten creator interactions (zero if absent), with $d=0$ for the latest. $\mathrm{Long}=n_{u,i}(t)/\max\{1,\max_j n_{u,j}(t)\}$ uses all accessible prior author interactions. $\mathrm{Pop}$ is a normalized log-frequency based only on TRAIN interactions. The mixture weights are fixed at 0.45/0.45/0.10; no specialist training or per-request weight fitting occurs. Both $B$ and $M$ rank the same candidates in each evaluated event. Source eligibility, ties and historical availability are specified in focused Supplement N14-S1 and the original research archive.

\subsection{Supervision Regimes and Frozen Policy Comparison}
\label{sec:relative-utility}
\label{sec:conditional-utility}

On the same event and eligible roster, the observed incremental value of the specialist is:
\begin{equation}
    \Delta_M(x)=u_K(M,x)-u_K(B,x).
    \label{eq:delta-memory}
\end{equation}
Its sampled-active and full-active versions, $\Delta_S$ and $\Delta_F$, are different offline labels. In the original sampled training-label construction, the observed target is retrospectively retained among 575 active candidates. This is permitted only for label computation, never for a live feature or online candidate generator.

For a pretarget descriptor vector $Z$, the regime-specific conditional value is
\begin{equation}
    \eta_r(z)
    =\mathbb{E}\!\left[\Delta_M(X)\mid Z=z,R=r\right].
    \label{eq:eta}
\end{equation}
Separate regressors estimate $\hat\eta_S$ or $\hat\eta_F$ and yield separately calibrated frozen policies $\pi_S,\pi_F$. Their common full-candidate outcome contrast is
\begin{equation}
    \mathcal{R}_{S\rightarrow F}
    =V_F(\pi_F)-V_F(\pi_S),
    \label{eq:candidate-supervision-transfer}
\end{equation}
with $V_F(\pi)=\mathbb E[u_{10}(B,X_F)+\pi(Z)\Delta_F(X)]$. This is the difference in realized full-F ranking quality between \emph{complete fitted policies}, not an isolated causal effect of changing labels at identical realized call rates.

\subsection{Pretarget Information and Invocation Rule}
\label{sec:framework-estimation}
\label{sec:decision-rule}
\label{sec:framework-controls}

$Z$ contains only already-observed user-history summaries, current eligible candidate descriptors and Base ranking scores. Current target identity, its observed position or NDCG, and outcome-derived history-state categories never enter the policy. M3 uses twelve descriptors, instantiated in Section~\ref{sec:exp-comparators}; exact definitions and leakage checks are retained in focused Supplement N14-S1 and the archived feature definitions. The fitted policy uses a threshold fixed through development out-of-fold predictions:
\begin{equation}
    a_{\tau_r}(z)=\mathbf{1}\!\left[
    \hat{\eta}_r(z)\mathrel{\succeq_r}\tau_r
    \right].
    \label{eq:utility-threshold}
\end{equation}
Here $\tau_r$ is selected under a nominal development Memory-call fraction $q_r$. The threshold is never reselected using additional evaluation targets. A DEV quota is not an enforced equal TEST call count or a statement about serving cost. The mean expected improvement has the usual selective-decision identity,
\begin{align}
    &\mathbb{E}\!\left[u_K^{\mathrm{sel}}(X;a)-u_K(B,X)\mid R=r\right] \\
    &\qquad=\mathbb{E}\!\left[a(Z)\Delta_M(X)\mid R=r\right]
    =\mathbb{E}\!\left[a(Z)\eta_r(Z)\mid R=r\right].
    \label{eq:expected-selective-gain}
\end{align}
which motivates estimating incumbent-relative value rather than standalone specialist quality \cite{mozannar2020defer,narasimhan2022posthoc}.

\section{Experimental Design}
\label{sec:experimental-setup}

The primary frozen experiment compares sampled- and full-candidate \emph{value-label supervision} for a fixed specialist on identical full-active M3 author-ranking targets. A previously examined KuaiLive room-ranking cohort supplies a short candidate-regime diagnostic; a shared DEV cohort describes the policies' allocation decisions. The historical-source null study belongs to the original multiplicity family but is not a parallel research question in this paper.

\subsection{Ranking Units, Cohorts and Candidate Regimes}
\label{sec:exp-data}

\paragraph{Paired room-ranking diagnostic.}
The original KuaiLive protocol ranks active \emph{rooms}, though Memory scores historical creator identities \cite{qu2026kuailive}. The same 10,222 previously examined target events, user histories and fixed dual-identity Base/Memory pair are evaluated with two candidate sets: $S$, the target plus 574 distinct active non-target rooms, and $F$, the contemporaneous full-active room roster. The Base's candidate-dependent standardized fusion scores and the candidate identities change together. This is a within-event retrospective sensitivity analysis; it is not a new M3 target cohort or a clean intervention on candidate count alone. Original checkpoint, eligibility and session-boundary conditions are in focused Supplement N14-S1 and the archived room protocol.

\paragraph{M3 full-candidate author ranking.}
M3 ranks persistent \texttt{author\_id} identities eligible through recorded active rooms. TRAIN ends on 23 March 2026 at 12:00 and DEV ends on 27 March 2026 at 14:00, with no unsupported source timezone assumed. The 24,995,148 TRAIN interactions establish the ranker vocabulary and TRAIN-only popularity. From the previously constructed M3 population, 50,049 full-active DEV requests (12,628 users) support policy fitting and exploratory allocation accounting. The original 47,575 target TEST events (12,533 users) were already evaluated in the precursor experiment and are not presented as an independent validation here. Each evaluation target refers to a TRAIN-known available author and requires at least two earlier valid user interactions. All event histories are updated only from earlier recorded observations.

\paragraph{Additional frozen policy targets.}
An outcome-blind freeze selected 30,000 more eligible M3 author-ranking event IDs (10,387 users) from the \emph{same original recording period}, excluding events scored in the initial author-ranking evaluation. Selection used five source dates crossed with four pretarget-history quartiles (20 cells), 1,500 selected events per cell. These targets are event-ID-disjoint, \emph{not} a future-period or user-disjoint replication. The same full-active candidates, Base, Memory and target-blind features are used for both policies. The nested 4,096-target historical-source comparison is retained in the complete original science archive and Supplement solely for original inferential-family disclosure, not as another main experiment.

\subsection{Fixed Models, Features and Label Regimes}
\label{sec:exp-comparators}

The M3 primary analysis uses the fixed SASRec and GRU4Rec checkpoint seeds 20261012 and unchanged Short--Long--Popularity Memory. The Base architecture uses 64-dimensional author embeddings, the last 16 interactions, and one SASRec attention or GRU4Rec recurrent layer. Three initial seeds per Base family were examined on the same original TEST population; this earlier robustness study is archived rather than interpreted as six independent TESTs.

Operationally, $Z$ has five Base-score summaries (top-two margin, score standard deviation, standardized top score, top score, mean score) and seven pretarget descriptors (past interactions, TRAIN-known past interactions, distinct past warm authors, maximum warm-author repeats, distinct recent warm authors, candidate-history support, log active-candidate count). Both S and F policies use this identical \emph{full-active decision-time} feature set. What differs is the offline label: original uncorrected target-retained sampled-active $\Delta_S$ versus full-active $\Delta_F$. There is no validated corrected sampled-only trained comparator. Full features, candidate generation, checkpoint selection and original policy objectives remain in focused Supplement N14-S1--N14-S2 and the original full protocol archive.

\subsection{Development Calibration, Freezing and Information Access}
\label{sec:exp-freeze}

The additional-target policy uses four user-group-disjoint DEV out-of-fold partitions and nominal 30\% DEV Memory-call calibration. Per Base, S and F receive separate development thresholds from those out-of-fold predictions; final predictors of the unchanged histogram-gradient-boosting capacity (120 iterations) are fitted on all DEV and use their already frozen respective thresholds. The same full-candidate feature contract and frozen Base/Memory scores apply to both arms. Four target-blind policy outputs and ranking lists were sealed before the additional cohort's target labels were used to calculate the results. Neither threshold nor realized call fraction was readjusted after target reveal.

This four-fold/120-iteration protocol is distinct from the original M3 selector study's five-fold/200-iteration DEV fitting and from the separate nested exploratory DEV comparisons. Observed targets may enter retrospective S labels and outcome evaluation, but not online $Z$, candidate availability, Memory history, selection thresholds or a target-dependent decision rule. Outcomes from earlier chronological events can contribute to later history only after they occurred; current or future targets cannot.

\subsection{Primary Estimand, Uncertainty and Scientific Boundaries}
\label{sec:exp-statistics}
\label{sec:exp-implementation}
\label{sec:exp-regimes}

The primary endpoint is event-level full-active NDCG@10. The estimand weights the 20 original date/history strata by their frequencies in the eligible residual TEST-source population. Policy differences are paired on the same event. We use 5,000 user-cluster bootstrap draws for two-sided 95\% CIs and 5,000 user-cluster sign randomizations for the frozen directional tests.

Holm adjustment preserves the \emph{original three-test prereveal family}, not an artificially reduced two-test family: (i) SASRec full-label policy minus sampled-label policy; (ii) corresponding GRU4Rec policy; (iii) authentic historical Memory versus within-event mean of three constrained history nulls on a nested 4,096-target subset. The third contrast is retained in the scientific Supplement/archive with its originally unmet cohort-specific pre-reveal TRAIN-only Popularity acceptance subgate; it is not used as evidence that the H1 policy effect is mediated by authentic source structure. Removing that study from the main narrative does not alter the original statistical family or its Holm-adjusted p-values.

The DEV decision-switch trace uses all 50,049 previously fitted DEV requests and is descriptive, not independently held-out confirmation or causal mediation. Realized raw and population-weighted Memory-call rates are reported separately: nominal DEV constraint does not make the new policies equal-budget on additional targets. Always Memory is the unrestricted quality reference. The only previously measured GPU latency belongs to a legacy pointwise selector in a separately warmed, counterbalanced 256-request DEV replay (three passes on RTX 3090); it does not estimate the newer F-aligned selector's online latency. Source manifests, user-level uncertainty implementation, family decisions and reproducibility limits remain in focused Supplement N14-S2 and the complete research archive.

\section{Results}
\label{sec:results}

The evidence follows one question: whether the candidate regime used to supervise the incumbent-relative value of a fixed Memory source affects frozen knowledge-use decisions and full-candidate ranking quality. A paired room-ranking comparison first establishes the candidate sensitivity of the evaluation target. The primary policy contrast then uses an additional same-period M3 author-ranking cohort, followed by descriptive DEV allocation accounting and the observed operating limitations. The room and author experiments have distinct ranked units and do not form an isolated causal chain.

\subsection{Candidate-Regime Sensitivity of the Supervision Target}
\label{sec:results-regimes}

The original KuaiLive \emph{room}-ranking comparison holds 10,222 evaluated events, their histories and the frozen Base/Memory ranker pair fixed while changing the eligible candidate set. With 575 sampled-active alternatives, Base NDCG@10 is $0.60709$ and Memory NDCG@10 is $0.56589$, giving Memory-minus-Base $-0.04120$. On the contemporaneous full-active roster, Base scores $0.38571$ and Memory scores $0.43202$, reversing the relative value to $+0.04631$. The within-event shift is $+0.08751$ (95\% paired user CI $[+0.08210,+0.09326]$). The crossed comparison in Table~\ref{tab:results-factorial} assigns $+0.08827$ to candidate membership and $-0.00076$ to the scoring reference. These are accounting dimensions: candidate identity, count and rank competition change together. This diagnostic motivates aligning the \emph{supervision target} with actual alternatives but does not independently test the later M3 author-ranking policy.

Under full-active evaluation, the F-supervised policies improve weighted NDCG@10 over S-supervised policies: SASRec $+0.005391$ (95\% paired-user CI $[+0.003646,+0.007174]$; Holm $p=0.000600$) and GRU4Rec $+0.003585$ (CI $[+0.001599,+0.005576]$; Holm $p=0.000800$).

With the same predeclared 20-cell eligible-population weights, the realized Memory-call fractions are 29.203\% (F) versus 30.537\% (S) for SASRec, and 29.008\% versus 30.809\% for GRU4Rec (focused Supplement Table N14-S1 (source Table S10.9)). \subsection{DEV Allocation: Which Requests Change Specialist Use?}
\label{sec:results-allocation}

On the shared 50,049 full-active M3 DEV requests, policy decisions disagree for 10,672 requests (21.32\%) under SASRec and 11,517 (23.01\%) under GRU4Rec. These are percentages of all evaluated DEV \emph{requests}, not of Memory invocations. The F-only versus S-only decisions number 5,350 versus 5,322 for SASRec and 5,639 versus 5,878 for GRU4Rec. F-only decisions have larger mean observed full-candidate Memory-minus-Base gains than displaced S-only decisions: $0.133417$ versus $0.076194$ for SASRec and $0.126600$ versus $0.079135$ for GRU4Rec. Both selected and displaced groups have positive mean benefit, consistent with improved prioritization among useful invocations rather than a simple positive-versus-negative filter.

DEV policies achieve NDCG@10 $0.302658$ (F) versus $0.296499$ (S) for SASRec and $0.303093$ versus $0.298123$ for GRU4Rec. The switch accounting is an algebraic partition of realized DEV policy value, not a causal decomposition of the separate additional 30,000-target policy contrast. Full DEV policy/call results, confidence intervals and the full-label adapted control are preserved in focused Supplement Table N14-S2 (source Table S10.14). This is explanatory same-DEV evidence, not another independent confirmatory TEST.

\subsection{Quality, Comparator and Operating Boundaries}
\label{sec:results-boundaries}

On the additional 30,000-target cohort, unrestricted Always Memory achieves weighted full-candidate NDCG@10 $0.348744$, above both tested selective F-supervised policies ($0.305446$ and $0.304530$). Thus the primary result concerns the observed policies under invocation limits, not unconstrained rank-quality dominance. The original sampled comparator was not statistically corrected: no scientifically admitted sampled-only corrected-S selector was trained and independently evaluated, so a valid correction could narrow the reported policy difference.

The earlier matched warmed DEV GPU replay also does not establish production savings: the \emph{original pointwise} Utility path averaged 1.76941 ms per request, versus 0.69165 ms for Always Memory and 0.72759 ms for Always Base. The newer F-supervised vectorized path was not measured end to end. A lower Memory-call fraction is therefore not evidence of reduced total serving latency or monetary cost. These constraints delimit the current offline decision-policy observation rather than defining another efficiency contribution.

\section{Discussion}
\label{sec:discussion}

\subsection{What Candidate-Aligned Supervision Changes}
\label{sec:discussion-values}

Our study concerns a use-time decision for an already fixed relationship source, not a new representation or routing algorithm. The paired room-ranking diagnostic shows why the target for that decision must be indexed by the evaluated candidates: Memory's advantage relative to Base reverses when candidate membership and the score-reference roster change. This is an observed regime contrast, not an intervention isolating the number of candidates. In the M3 author-ranking study, the separate complete-policy comparison supports the practical consequence: full-candidate supervision is associated with better full-active ranking under the tested frozen F/S policy configurations.

The shared DEV switch trace makes the decision difference interpretable. The policies disagree on 21--23\% of requests, and calls added under F supervision have greater mean observed Memory-minus-Base value than displaced S-only calls. Both groups nevertheless have positive average value. The pattern is therefore consistent with a shift in the \emph{priority} of useful specialist calls, not simply filtering out all harmful calls. This is descriptive accounting on the fitting/development population, not causal mediation or an independent confirmation of the additional-target comparison.

\subsection{What This Comparison Cannot Establish}
\label{sec:discussion-validity}

The sampled-label comparator retains the observed target retrospectively among 575 alternatives and uses no validated sampling correction. A defensible sampled-only correction could narrow the observed F-versus-S policy difference; we did not train or evaluate a selector using such corrected labels and cannot rule out that alternative. The separately fitted arms are calibrated with different development thresholds, and their additional-target invocation rates differ. The result therefore concerns the tested \emph{complete frozen policies}, not a strictly matched-call, label-only causal contrast.

The additional M3 targets are event-ID-disjoint from the original evaluation, but occur in the same recording period and may share users or earlier history. The room-ranking diagnostic uses a different ranked unit and Base checkpoint; it motivates the candidate question without isolating the mechanism in the author-ranking cohort. Observed single-positive targets are also subject to logging and exposure limitations \cite{pereira2025samplingreliability}. Accordingly these results support the stated offline policy comparison, not a future-period replication or causal online user outcomes.

The original prereveal Holm family included a separate nested authentic-history-versus-null comparison. That experiment is preserved in the Supplement and research archive, not used as a parallel main-paper contribution or as proof of the H1 mechanism. Its original acceptance protocol was \emph{partially completed}: the nested cohort's specified TRAIN-only Popularity margin was \emph{not measured and sealed before target reveal}. The completed DEV analogue cannot retrospectively supply this missing check. Retaining this disclosure protects the original multiplicity record without enlarging the present paper's question.

Finally, Always Memory yields greater unconstrained full-candidate ranking quality than either selective F policy. A warmed DEV replay of the original pointwise Utility selector was slower than unconditional Memory; the newer vectorized F policy has no measured end-to-end serving latency. Lower invocation fractions therefore cannot establish deployment-savings or monetary benefits. They describe one policy resource dimension and motivate further evaluation only when actual capacity or cost constraints are specified.

\section{Conclusion}
\label{sec:conclusion}

The candidate regime used to supervise the relative value of fixed historical relationship Memory matters for the observed decisions and full-candidate ranking outcomes of the tested frozen selection policies. A paired room-ranking diagnostic establishes why the relative-value label is candidate-dependent; a separate same-period M3 author-ranking comparison shows higher weighted full-candidate NDCG and lower naturally realized Memory-call fractions for full-supervised policies than for the original uncorrected sampled-supervised policies. The DEV allocation trace provides descriptive, not causal, insight into the changed calls.

This is a bounded empirical knowledge-use supervision result, not a new deferral theorem or proof of deployment efficiency. Corrected sampled-label policies, strict resource-matched evaluation, independent future-period cohorts and end-to-end serving measurements remain untested alternatives or transfer conditions.
