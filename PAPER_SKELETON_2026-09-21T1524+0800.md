# 1. Recommended title

## Primary title

> **Learning When Memory Helps: Conditional Specialist Utility for Live-Streaming Recommendation**

## Alternative title

> **When Does Memory Help? Learning Conditional Utility for Selective Memory in Live-Streaming Recommendation**

Avoid centering the title on generic *adaptive computation*, *slow/fast thinking*, *uncertainty-aware recommendation*, *agentic recommendation*, or *memory-augmented recommendation*. Those framings now have direct collisions in 2025–2026 literature. The defensible novelty is the **conditional relative utility of a memory specialist that is globally inferior to a strong base but locally beneficial**.

---

# 2. Core thesis

> **Explicit memory is not a uniformly stronger recommender but a complementary specialist whose marginal predictive utility varies across user states and temporal regimes; learning this conditional relative utility enables selective memory escalation beyond strong identity-aware sequential baselines.**

The paper is therefore not primarily “a memory recommender that beats SASRec.” It is a mechanism paper about **conditional specialist utility**.

---

# 3. Problem formulation

Let `B` denote a strong sequential base recommender and `M` an explicit relationship-memory specialist. For an interaction state `x`, define the specialist’s conditional relative utility as

\[
\Delta_m(x)=U(M,x)-U(B,x).
\]

Learn a dev-only utility predictor

\[
\hat{\Delta}_m(x)=g(s_x,c_B(x)),
\]

where:

- `s_x`: user / interaction state features;
- `c_B(x)`: confidence / ambiguity features derived from the base model;
- `g`: a utility estimator (HGB in the frozen scientific chain; Ridge/tiny-MLP as deployment variants).

Escalate to memory when

\[
\hat{\Delta}_m(x)>\tau,
\]

with `tau` selected using development data only.

## Preferred terminology

- conditional relative utility;
- marginal predictive utility;
- conditional specialist utility;
- memory escalation;
- memory specialist / memory expert;
- identity-aware sequential base.

## Avoid

- causal treatment effect;
- “first selective recommender”;
- “first uncertainty-aware recommender”;
- “first memory recommender”;
- “agent beats SASRec”;
- “Selective Memory universally beats DS-Frame”;
- causal GMV / conversion lift;
- describing current MemoryFusion as an LLM agent.

# 4. Recommended research questions

## RQ1 — Is explicit memory uniformly superior to a strong sequential recommender?

**Answer:** no. Memory is globally inferior in ordinary LOO evaluation but remains beneficial on identifiable subsets.

## RQ2 — Can positive memory-relative utility be predicted from user state and base confidence?

**Answer:** yes. State + confidence materially outperforms simple history/state heuristics in the frozen v2 chain.

## RQ3 — Is the gain merely a persistent-streamer identity shortcut?

**Answer:** no under the Dual-ID control. Even when persistent streamer identity is explicitly absorbed into a streamer-heavy sequential base, Memory remains globally inferior while selective Memory adds significant value.

## RQ4 — Is Selective Memory just generic fast/slow adaptive computation?

**Answer:** no. DS-Frame routes toward a globally superior slow path; Selective Memory routes toward a globally inferior-on-average but conditionally complementary specialist.

## RQ5 — Does the prevalence of positive memory utility change across temporal regimes, and what does selective execution actually cost?

**Answer:** yes. Under strict temporal shift, memory becomes broadly useful and invocation expands. End-to-end cost depends jointly on selector cost and specialist invocation rather than invocation rate alone.

# 5. Core contributions

## C1 — Empirical phenomenon: globally inferior, conditionally useful specialist

Averaged model ranking hides heterogeneous relative utility.

Frozen LOO evidence:

- SASRec NDCG@10: ~0.61010
- Always MemoryFusion: ~0.56770
- Selective-v2 HGB: ~0.62323
- Selective − SASRec: ~+0.01313 / +2.15%
- bootstrap 95% CI strictly positive.

The scientific observation is not “memory is stronger,” but that a **globally weaker specialist can have predictable local positive utility**.

## C2 — Method: predict specialist-minus-base utility, not generic difficulty

The selector predicts whether memory will improve over the base, using user-state and base-confidence signals.

Frozen SASRec-v2 ablation:

- history threshold: ~0.61555
- state-only HGB: ~0.61558
- state-only Ridge: ~0.61639
- state+confidence Ridge: ~0.62178
- state+confidence Tree: ~0.62356
- state+confidence HGB: ~0.62323

Interpretation: base confidence contributes beyond coarse history/state signals.

## C3 — Mechanism defense: not merely persistent streamer identity

Primary room-level identity control:

- room SASRec test: 0.3150925
- streamer SASRec test: 0.6003083
- Dual-ID test: **0.6078439**
- MemoryFusion: **0.5658875**
- Frozen Selective Dual+Memory: **0.6210175**
- Selective − Dual-ID: **+0.0131736**
- 95% CI: **[+0.0101838,+0.0161169]**
- frozen memory invocation: **14.2536%** (1457/10222)
- dev fusion weight: room 0.1 / streamer 0.9.

Canonical claim:

> **Even after persistent streamer identity is explicitly absorbed into a strong dual-ID sequential recommender, memory remains globally inferior yet conditionally complementary.**

## C4 — Temporal finding: utility is regime-dependent

GTS-Last:

- Dual-ID: 0.4961552
- Always Memory: 0.5736936
- Selective: 0.5689723
- test invocation: 59.80%
- selective captures ~93.9% of full-memory absolute improvement.

GTS-Successive:

- Dual-ID event NDCG@10: 0.4030069
- Always Memory: 0.5036781
- Selective: 0.5004335
- test invocation: 74.73%
- selective captures ~96.8% of full-memory absolute improvement.

Canonical claim:

> **The prevalence of positive memory utility is regime-dependent. Under temporal distribution shift, memory can become broadly valuable, while selective routing retains most of its predictive benefit with fewer specialist invocations.**

Do not claim Selective always maximizes accuracy: Always Memory is slightly higher in both GTS settings.

## C5 — Distinction from generic adaptive computation

DS-Frame streamer-projected live-room collision defense:

- DS projected fast: 0.5296201
- DS projected full slow: 0.6321606
- Dual-ID: 0.6078439
- Memory: 0.5658875

Mechanism contrast:

- DS-Frame: slow path is **globally superior** to fast path;
- Selective Memory: memory specialist is **globally inferior** to the strong identity-aware base but beneficial on identifiable subsets.

Canonical paragraph:

> **Unlike adaptive-computation routing, where the slow path is globally superior to the fast path, our memory expert is globally inferior to an identity-aware sequential base yet beneficial on identifiable subsets. Selective memory therefore models conditional specialist utility rather than merely allocating additional computation to harder instances.**

Do not claim routing superiority over DS-Frame. In matched-budget comparisons DS often has stronger within-system routing gain; our higher absolute NDCG largely reflects a stronger base.

## C6 — Systems finding: selector complexity is part of selective-inference cost

Gate-compression results:

| Gate | NDCG@10 | Delta vs Dual-ID | Invocation | Mean end-to-end latency |
|---|---:|---:|---:|---:|
| HGB | 0.621018 | +0.013174 | 14.25% | 2.0066 ms |
| Ridge | **0.623876** | **+0.016032** | 30.99% | **1.3872 ms** |
| tiny MLP | 0.617076 | +0.009232 | **10.37%** | **1.2720 ms** |

Selector-only mean latency:

- HGB: 0.6171 ms
- Ridge: 0.00242 ms
- tiny MLP: 0.00575 ms

Canonical systems claim:

> **End-to-end selective-inference cost depends jointly on selector complexity and specialist invocation. A lighter utility estimator can invoke memory more often yet remain faster overall.**

HGB remains the frozen primary scientific selector because the complete robustness/GTS chain was built around it. Ridge is a deployment variant, not a retroactive replacement for every experiment.

# 6. Narrative logic

## Act 1 — The paradox

Explicit long-term relationship memory should intuitively help live-stream recommendation, yet always-on MemoryFusion is substantially worse than a tuned sequential recommender.

## Act 2 — Average ranking hides heterogeneity

Per-instance analysis shows that memory still helps identifiable subsets. This motivates modeling **relative specialist utility** instead of assuming global model superiority.

## Act 3 — Learn when memory helps

Predict `Delta_memory(x)` from user state and base confidence. Selective escalation significantly improves strong sequential bases.

## Act 4 — Rule out the identity shortcut

Use the room+streamer Dual-ID base. Even though the optimal dev fusion is 90% streamer-weighted, Memory remains globally worse but selectively useful.

## Act 5 — Rule out generic slow-thinking routing

Use DS-Frame as a mechanism collision defense. Its slow path is globally stronger; our memory specialist is globally weaker. Therefore the routing objective is qualitatively different.

## Act 6 — Reveal regime dependence

Under strict temporal splits, aggregate model ordering reverses: memory becomes broadly useful and escalation rises from ~14% to ~60–75%. The object of interest is therefore the **distribution of relative utility**, not a fixed model ranking.

## Act 7 — Close with deployment cost

Latency profiling shows that the selector itself can dominate overhead. Ridge/tiny-MLP compression demonstrates that invocation rate alone is not a valid proxy for end-to-end cost.

# 9. Novelty boundary after 2026-09-21 web scan

Closest collisions now include:

1. **DS-Frame / Recommender System as Slow and Fast Thinkers** — adaptive fast/slow recommendation with learned selector and computation budgets. High collision for generic adaptive-computation claims, but its slow path is globally stronger.
2. **GUIDER (AAAI 2026)** — uncertainty-guided dynamic re-ranking for LLM recommenders. Collision for uncertainty-aware selective execution, but not explicit memory-relative utility beyond an identity-aware sequential base.
3. **MemRec (ACL 2026)** — collaborative memory-augmented agentic recommendation. High collision for generic “memory-augmented recommender” claims, but it focuses on collaborative semantic memory for LLM-based recommendation rather than selective escalation of a globally inferior memory specialist.
4. **MoE-SLMRec / other MoE recommenders** — context-dependent expert routing. Collision for generic expert-routing claims, but not the specialist-minus-base utility setting.
5. **DCGLive (WWW 2026)** — strong direct competitor for dynamic room-level live-stream recommendation, not for conditional memory utility.
6. **MRB4LS (ESWA 2025)** — repeated-behavior live-stream recommendation, close to the repeat-relationship motivation but not selective specialist utility.
7. **LiveRec** — dynamic item availability and repeat consumption; important baseline/external dataset lineage.
8. **OneLive (2026)** — industrial dynamic generative live-stream recommendation; close to temporal/dynamic live-stream framing but not explicit conditional memory utility.

As of this scan, no retrieved work was found that simultaneously combines:

- a strong sequential base;
- a separately interpretable explicit memory specialist;
- specialist globally inferior to the base;
- dev-trained prediction of specialist-minus-base utility;
- explicit identity-control showing the effect survives persistent identity absorption;
- strict temporal evidence that specialist utility prevalence changes by regime;
- decomposition of selector cost vs specialist invocation cost.

**Do not claim “first.”** State instead that the combination appears distinct from the closest retrieved literature and position novelty at the mechanism level.

# 11. Canonical abstract logic

A future abstract should follow this order:

1. **Problem:** explicit memory seems useful in dynamic recommendation, but strong sequential models already capture much historical signal.
2. **Observation:** always-on explicit memory is globally weaker than strong sequential baselines.
3. **Hypothesis:** its utility is heterogeneous and conditionally predictable.
4. **Method:** predict memory-minus-base utility from user state and base confidence and selectively escalate memory.
5. **Main evidence:** significant gain over SASRec and identity-aware Dual-ID despite Memory being globally worse.
6. **Mechanism evidence:** identity control + DS-Frame contrast.
7. **Temporal evidence:** utility prevalence shifts under GTS and invocation expands.
8. **Systems evidence:** selector cost matters; lightweight utility estimators improve the latency frontier.
9. **Takeaway:** memory should be treated as a conditional specialist, not a universally stronger recommender.

# 12. Current manuscript positioning

The paper should be sold as a **mechanism-driven recommender-systems study with practical systems validation**, not as an “agent” paper and not as a leaderboard paper.

The memorable scientific message is:

> **A specialist can be worse on average yet valuable enough on predictable subsets to improve a strong base; the prevalence of those subsets itself changes across temporal regimes.**
