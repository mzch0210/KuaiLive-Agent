## 1. Recommended title

### Primary title

> **Learning When Memory Helps: Conditional Specialist Utility for Live-Streaming Recommendation**

### Alternative title

> **When Does Memory Help? Learning Conditional Utility for Selective Memory in Live-Streaming Recommendation**

Avoid centering the title on generic “thinking”, “slow/fast”, “adaptive computation”, or “agentic recommendation”. DS-Frame (CIKM 2026) now directly occupies the generic fast/slow adaptive-recommendation framing.

---

## 2. One-sentence thesis

> **Explicit memory is not a uniformly stronger recommender but a complementary specialist whose marginal predictive utility varies across user states and temporal regimes; learning this conditional relative utility enables selective memory escalation beyond strong identity-aware sequential baselines.**

The paper is therefore not primarily “a memory recommender that beats SASRec”. It is a mechanism paper about **conditional specialist utility**.

---

## 3. Core formalization

Let `B` be a strong sequential base recommender and `M` an explicit memory specialist. Define the per-instance relative utility:

\[
\Delta_m(x)=U(M,x)-U(B,x)
\]

Learn a dev-only utility predictor:

\[
\hat{\Delta}_m(x)=g(s_x,c_B(x))
\]

where:

- `s_x`: user / interaction state features;
- `c_B(x)`: base-model confidence / ambiguity features.

Invoke memory if:

\[
\hat{\Delta}_m(x)>\tau
\]

Use terminology:

- conditional relative utility;
- marginal predictive utility;
- memory escalation;
- memory specialist / memory expert;
- conditional specialist utility.

Avoid:

- causal treatment effect;
- “agent generally beats SASRec”;
- “first selective recommender”;
- “first uncertainty-aware recommender”;
- “first memory recommender”;
- “Selective Memory is generally faster/better than DS-Frame”.

## 4. Recommended contribution structure

### C1 — Empirical phenomenon: globally inferior, conditionally useful specialist

Averaged model ranking hides heterogeneous relative utility. In ordinary leave-one-out evaluation, explicit MemoryFusion is globally weaker than strong sequential recommendation, but identifiable subsets show positive memory utility.

Key evidence:

- SASRec: ~0.61010 NDCG@10
- Always MemoryFusion: ~0.56770
- Selective-v2 HGB: ~0.62323
- gain: +0.01313 / +2.15%, bootstrap CI strictly positive.

This is the primary scientific phenomenon.

### C2 — Method: predict relative utility, not generic difficulty

The gate predicts whether the memory specialist will outperform the base, using user state plus base confidence. This differs from merely estimating sample difficulty or uncertainty.

Important ablation evidence from the frozen SASRec experiment:

- history threshold: ~0.61555
- state-only HGB: ~0.61558
- state-only Ridge: ~0.61639
- state+confidence Ridge: ~0.62178
- state+confidence Tree: ~0.62356
- state+confidence HGB: ~0.62323

Interpretation: confidence adds information beyond history/state alone.

### C3 — Mechanism defense: not merely persistent streamer identity

Primary room-level identity control explicitly models both ephemeral room sequence and persistent streamer sequence.

Frozen room-level evidence:

- room SASRec test: 0.3150925
- streamer SASRec test: 0.6003083
- Dual-ID test: **0.6078439**
- MemoryFusion: **0.5658875**
- Selective Dual+Memory: **0.6210175**
- Selective − Dual-ID: **+0.0131736**, 95% CI **[+0.0101838,+0.0161169]**
- frozen memory invocation: **14.2536%** (1457/10222)
- Dual-ID dev fusion weight: room 0.1 / streamer 0.9.

Therefore, the gain survives even when persistent streamer identity is already strongly absorbed by the sequential base.

Recommended claim:

> **Even after persistent streamer identity is explicitly absorbed into a strong dual-ID sequential recommender, memory remains globally inferior yet conditionally complementary.**

### C4 — Temporal finding: memory utility is regime-dependent

Strict global temporal evaluation reveals that memory utility is not an intrinsic fixed property.

GTS-Last:

- Dual-ID: 0.4961552
- Always Memory: 0.5736936
- Selective: 0.5689723
- memory invocation: 59.80%
- selective preserves ~93.9% of full-memory absolute gain.

GTS-Successive:

- Dual-ID event NDCG@10: 0.4030069
- Always Memory: 0.5036781
- Selective: 0.5004335
- memory invocation: 74.73%
- selective preserves ~96.8% of full-memory absolute gain.

Interpretation:

> **The prevalence of positive memory utility shifts across temporal regimes. Under distribution shift, memory can become broadly valuable, while selective routing retains most of the gain with fewer invocations.**

Do not claim Selective always maximizes accuracy: Always Memory is slightly higher in both GTS settings.

### C5 — Distinction from generic adaptive computation

DS-Frame is now an important collision baseline, not an opponent that must be “beaten”.

Streamer-projected room collision defense:

- DS projected fast: 0.5296201
- DS projected full slow: 0.6321606
- Dual-ID: 0.6078439
- Memory: 0.5658875

Mechanism difference:

- DS: slow path is **globally superior** to fast path.
- Ours: memory specialist is **globally inferior** to the identity-aware base but is useful on identifiable subsets.

Recommended paragraph:

> **Unlike adaptive-computation routing, where the slow path is globally superior to the fast path, our memory expert is globally inferior to an identity-aware sequential base yet beneficial on identifiable subsets. Selective memory therefore models conditional specialist utility rather than merely allocating additional computation to harder instances.**

Matched-budget DS results are for collision defense. Do not claim routing superiority over DS-Frame; DS often has stronger within-system gain per routing budget, while our higher absolute NDCG largely reflects a stronger base.

### C6 — Systems finding: selector cost matters separately from invocation rate

Latency-compression experiment shows selective inference cost is not controlled by invocation rate alone.

Frozen / compressed room-level gate results:

| Gate | NDCG@10 | Delta vs Dual-ID | Invocation | Mean E2E latency |
|---|---:|---:|---:|---:|
| HGB | 0.621018 | +0.013174 | 14.25% | 2.0066 ms |
| Ridge | **0.623876** | **+0.016032** | 30.99% | **1.3872 ms** |
| tiny MLP | 0.617076 | +0.009232 | **10.37%** | **1.2720 ms** |

Selector-only mean latency:

- HGB: 0.6171 ms
- Ridge: 0.00242 ms
- tiny MLP: 0.00575 ms

Recommended systems claim:

> **End-to-end selective-inference cost depends jointly on selector complexity and specialist invocation. A lighter utility estimator can invoke memory more often yet remain faster overall.**

HGB remains the frozen primary scientific gate because the complete robustness/GTS chain was built around it. Ridge is a lightweight deployment variant, not a retroactive replacement for every experiment.

## 5. Recommended research questions

### RQ1 — Does explicit memory have uniform or conditional value beyond a strong sequential base?

Answer: conditional, not uniform.

Evidence: SASRec/Memory/Selective and Dual-ID/Memory/Selective.

### RQ2 — Can positive relative memory utility be predicted from user state and base confidence?

Answer: yes; confidence adds material signal beyond simple history/state heuristics.

Evidence: v2 ablations and lightweight-gate results.

### RQ3 — Is selective-memory gain reducible to persistent identity representation?

Answer: no under the Dual-ID control.

Evidence: streamer-heavy Dual-ID remains globally stronger than Memory, yet selective memory still adds +0.01317 with positive CI.

### RQ4 — Is this just generic fast/slow adaptive computation?

Answer: no; the specialist ordering is reversed. DS routes toward a globally superior slow path; selective memory identifies local positive utility from a globally inferior specialist.

Evidence: DS streamer and streamer-projected room collision defenses.

### RQ5 — How does memory utility change under temporal shift, and what does selective execution cost?

Answer: prevalence of positive utility is regime-dependent; routing expands under temporal shift. End-to-end cost is jointly determined by selector and specialist costs.

Evidence: GTS-Last, GTS-Successive, latency and gate-compression experiments.

## 6. Recommended paper narrative

### Act 1 — The paradox

Long-term explicit memory should intuitively help live-stream recommendation, but always-on MemoryFusion is substantially worse than a tuned sequential model.

### Act 2 — Average ranking hides heterogeneity

Per-instance analysis shows memory is still beneficial for identifiable subsets. This motivates conditional relative-utility prediction rather than always-on memory.

### Act 3 — Learn when memory helps

Define and predict `Delta_memory(x)`. Selective escalation yields significant gains beyond strong sequential bases.

### Act 4 — Rule out the identity shortcut

Introduce the Dual-ID room+streamer base. Even with a 90%-streamer dev fusion weight, Memory remains globally worse but conditionally useful.

### Act 5 — Rule out generic slow-thinking routing

Use DS-Frame collision defense. The DS slow path is globally superior; the memory specialist is globally inferior. Therefore the core problem is different.

### Act 6 — Reveal regime dependence

Strict temporal splits reverse the aggregate ranking: memory becomes broadly useful and routing rates rise from ~14% to ~60–75%. The important object is the **distribution of relative utility**, not a fixed global ranking.

### Act 7 — Close with systems cost

Latency profiling shows the selector can dominate overhead. Ridge/tiny-MLP compression demonstrates that invocation frequency alone is not an adequate proxy for end-to-end cost.

## 8. Updated novelty scan (web, 2026-09-21)

### Closest collision A — DS-Frame, CIKM 2026

**Recommender System as Slow and Fast Thinkers** (arXiv:2609.02671; accepted CIKM 2026) studies adaptive fast/slow sequential recommendation, a learned selector and controllable computation budgets.

Collision risk: **high for generic routing / adaptive-computation framing**, but not identical to conditional memory specialist utility.

URL: https://arxiv.org/abs/2609.02671

### Closest collision B — GUIDER, AAAI 2026

**GUIDER: Uncertainty Guided Dynamic Re-ranking for Large Language Models Based Recommender Systems** uses uncertainty to decide dynamic LLM re-ranking.

Collision risk: **medium/high for uncertainty-guided selective execution**, but it routes LLM reranking rather than a globally inferior explicit memory specialist relative to an identity-aware sequential base.

URL: https://github.com/Wang-Xujing/GUIDER

### Closest live-streaming work — DCGLive, WWW 2026

**Room Matters: Dynamic Room-level Collaboration Information Modeling for Live Streaming Recommendation** models room-level dynamic collaboration and ephemeral room state.

Collision risk: **high for room-level live-streaming task**, low for selective memory utility.

DOI: https://doi.org/10.1145/3774904.3792241

### Repeated-behavior live-streaming recommendation — ESWA 2025

**Live streaming recommendation based on multiple types of repeated behaviors** explicitly models repeated enter/chat/gift behavior through graph learning.

Collision risk: **medium for repeat-behavior motivation**, low for conditional specialist utility/routing.

DOI: https://doi.org/10.1016/j.eswa.2025.128217

### KuaiLive-M3, 2026

Provides multi-modal, multi-domain and explicit-feedback live-streaming benchmarks; important external-validation opportunity, but not a selective-memory utility method.

URL: https://arxiv.org/abs/2607.24862

### Selective memory literature outside recommendation

Recent LLM/RAG work studies selective write-time memory or selective remembrance. This makes the generic phrase “selective memory” less novel across AI, so novelty should be placed on **conditional relative utility of an explicit memory specialist beyond a strong sequential recommender**, not on the phrase itself.

Example: https://arxiv.org/abs/2603.15994

### Novelty conclusion

As of 2026-09-21, no retrieved work exactly matches all of the following combination:

1. strong sequential recommendation base;
2. explicit memory as a separately interpretable specialist;
3. memory is globally inferior to the base;
4. utility prediction targets specialist-minus-base relative utility;
5. gain survives explicit persistent-identity absorption;
6. specialist usefulness changes sharply across temporal regimes;
7. selective inference cost is decomposed into selector cost and specialist-invocation cost.

Therefore novelty remains defensible, but the paper must **not** claim novelty for generic routing, uncertainty-aware recommendation, memory-enhanced recommendation, or fast/slow computation.

### Supported

- explicit memory is conditionally complementary rather than uniformly stronger;
- relative utility can be predicted well enough to improve strong sequential baselines;

## 10. Canonical paper-ready framing

> **Aggregate model rankings can conceal specialist value. In live-stream recommendation, explicit memory is often weaker than a strong identity-aware sequential recommender on average, yet it becomes predictably superior for specific user states and under particular temporal regimes. We formulate selective memory as conditional relative-utility estimation: the system predicts when the memory specialist has positive marginal predictive utility over the base and escalates only then. Identity controls, strict temporal evaluation, adaptive-computation collision defenses, and inference-cost profiling show that this phenomenon is neither a simple streamer-identity shortcut nor conventional routing to a globally stronger slow model.**
