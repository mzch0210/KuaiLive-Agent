# 2. Final core thesis after P0

> **Explicit relationship memory has no fixed global ordering relative to a strong identity-aware sequential recommender. Its marginal ranking utility varies across user states, candidate universes, and temporal regimes. In sampled-active LOO it is globally inferior yet locally complementary; under full-active ranking and strict temporal shift it becomes broadly valuable. Learning conditional relative utility enables selective memory escalation that exploits this heterogeneity beyond generic hard-case routing.**

This is stronger and safer than treating “globally inferior memory” as a universal property. Global inferiority is an important **regime-specific phenomenon**, while **regime-dependent relative utility** is the overarching scientific object.

---

# 3. Novelty boundary

The paper does **not** claim invention of generic expert routing or deferral. Learning-to-Defer already studies instance-wise allocation between predictors/experts, including fixed-expert/two-stage settings and accuracy–cost trade-offs (e.g., Mao, Mohri & Zhong, ICML 2025: https://proceedings.mlr.press/v267/mao25c.html).

The defensible novelty is the combination specific to live recommendation:

1. a separately interpretable **explicit relationship-memory specialist**;
2. a strong room+streamer **identity-aware sequential base**;
3. a regime in which Memory is **globally inferior but locally complementary**;
4. direct estimation of **specialist-minus-base ranking utility**, not merely base difficulty;
5. evidence that the **global ordering reverses with candidate universe and temporal regime**;
6. full-active legality/control showing the effect is not a 575-negative artifact;
7. deployment evidence showing selector complexity and specialist invocation jointly determine cost.

Avoid “first” claims.

# 4. Primary task and formulation

The manuscript uses **next-live-room recommendation** as the primary task. Earlier streamer-only SASRec results become supporting/appendix evidence.

Let `B` be the strong Dual-ID room+streamer sequential base, `M` the explicit relationship-memory specialist, and `u_K(A,x)` event-level ranking utility such as NDCG@10.

Realized relative memory utility:

\[
\Delta_m(x)=u_K(M,x)-u_K(B,x).
\]

Conditional expected relative utility:

\[
\eta(z,r)=\mathbb E[\Delta_m(X)\mid Z=z,R=r],
\]

where:

- `z=(s_x,c_B(x))` combines user/interaction state and base-confidence information;
- `r` denotes the evaluation/serving regime, including candidate-universe and temporal regime.

Within a fixed regime, learn on development data only:

\[
\hat\eta(z)=g(z),
\]

and escalate to Memory when

\[
\hat\eta(z)>\tau.
\]

`utility` means **offline ranking utility**, not GMV, conversion, satisfaction, or a causal treatment effect.

# 5. Research questions

## RQ1 — Does explicit relationship memory have a fixed global advantage over a strong identity-aware sequential recommender?

**No.** Aggregate ordering reverses across regimes:

- sampled-active LOO: Memory < Dual-ID;
- full-active LOO: Memory > Dual-ID;
- strict temporal GTS: Memory > Dual-ID by still larger margins.

The correct scientific object is relative utility, not a single global model ranking.

## RQ2 — Can memory-relative utility be predicted beyond persistent identity and generic base difficulty?

**Yes.** The gain survives the streamer-heavy Dual-ID identity control. In both sampled-active and full-active settings, relative-utility routing significantly outperforms a same-feature base-difficulty router at an identical specialist budget.

## RQ3 — How do candidate universe and temporal regime change memory utility and escalation behavior?

Candidate expansion from 575 sampled-active candidates to all legal active rooms reverses the Memory−Base aggregate sign and increases native escalation from ~14% to ~64%. Strict temporal shift also makes Memory broadly valuable with ~60–75% escalation.

## RQ4 — What are the accuracy–invocation–latency trade-offs of selective memory?

Selector cost can dominate incremental latency; invocation rate alone is not a valid compute proxy.

# 6. Four contributions

## C1 — Regime-dependent relative utility of explicit relationship memory

The main empirical finding is not a fixed ranking between Memory and the sequential base.

| Regime | Base NDCG@10 | Always Memory | Memory − Base | Selective | Invocation |
|---|---:|---:|---:|---:|---:|
| Sampled-active LOO (575) | 0.607844 | 0.565887 | **−0.041956** | **0.621018** | 14.25% |
| Full-active LOO (~8.3k avg.) | 0.398353 | 0.432019 | **+0.033666** | **0.451801** | 64.44% |
| GTS-Last | 0.496155 | 0.573694 | **+0.077538** | 0.568972 | 59.80% |
| GTS-Successive | 0.403007 | 0.503678 | **+0.100671** | 0.500434 | 74.73% |

Interpretation:

> **The prevalence and aggregate sign of memory-relative utility are regime-dependent.**

Do not compare absolute NDCG values across candidate universes as though they were the same ranking difficulty.

## C2 — Relative-utility routing contains information beyond generic difficulty

### Sampled-active regime

At the exact frozen HGB budget (`K=1457`, 14.25%):

- difficulty-router gain: **+0.007716**;
- relative-utility-router gain: **+0.013174**;
- Utility − Difficulty: **+0.005458**;
- 95% CI: **[+0.002659,+0.008464]**.

Predicted vs realized utility:

- Spearman `rho = 0.2049`;
- bottom-decile realized utility: **−0.1435**;
- top-decile realized utility: **+0.1072**.

The frozen gate captures ~**17.0%** of exact-K oracle gain.

### Full-active regime

At the exact native HGB budget (`K=6587`, 64.44%):

- difficulty-router gain: **+0.039017**;
- relative-utility-router gain: **+0.053448**;
- Utility − Difficulty: **+0.014431**;
- 95% CI: **[+0.010938,+0.017908]**.

Predicted vs realized utility:

- Spearman `rho = 0.2399`;
- bottom-decile realized utility: **−0.1430**;
- top-decile realized utility: **+0.1774**.

The gate captures ~**50.3%** of exact-K oracle gain.

Canonical claim:

> **Specialist-minus-base prediction is not reducible to generic hard-case detection: at identical invocation budgets, direct relative-utility routing significantly outperforms routing based only on base difficulty in both candidate regimes.**

Use “modestly predictive but decision-useful,” not “well calibrated.”

## C3 — Strong identity control + full-active validity + temporal robustness

### Identity control

Sampled-active primary identity result:

- Room SASRec: 0.315093
- Streamer SASRec: 0.600308
- Dual-ID: **0.607844**
- Memory: **0.565887**
- Selective: **0.621018**
- Selective − Dual-ID: **+0.013174**, positive bootstrap CI
- dev alpha: room 0.1 / streamer 0.9.

Thus the sampled-regime complementarity survives explicit persistent-streamer absorption.

### Full-active legality / candidate robustness

All 10,222 positives are metadata-active. Test candidates:

- mean **8,269.1**;
- median **8,131.5**;
- p95 **12,301**;
- max **13,266**.

The full-active dev alpha remains room 0.1 / streamer 0.9.

**Strict transfer** from the sampled gate:

- Selective − Base: **+0.031799**
- CI **[+0.028143,+0.035554]**
- invocation 29.18%.

**Full-active-native** dev-only recalibration:

- Base: 0.398353
- Memory: 0.432019
- Selective: **0.451801**
- Selective − Base: **+0.053448**
- CI **[+0.048252,+0.058836]**
- invocation 64.44%
- HR@10: Base 0.519174 / Memory 0.515750 / Selective **0.557523**.

The full-active result closes sampled-candidate dependence while revealing candidate-regime reversal.

### Strict temporal robustness

GTS-Last and GTS-Successive show that Memory becomes broadly valuable and Selective retains ~94–97% of full-memory absolute gain with fewer invocations. Do not claim Selective always beats Always Memory in GTS.

## C4 — Deployment implication: selector complexity is part of selective-inference cost

| Gate | NDCG@10 | Delta vs Dual-ID | Invocation | Mean end-to-end latency |
|---|---:|---:|---:|---:|
| HGB | 0.621018 | +0.013174 | 14.25% | 2.0066 ms |
| Ridge | **0.623876** | **+0.016032** | 30.99% | **1.3872 ms** |
| tiny MLP | 0.617076 | +0.009232 | **10.37%** | **1.2720 ms** |

Selector-only mean latency:

- HGB ~0.617 ms;
- Ridge ~0.00242 ms;
- tiny MLP ~0.00575 ms.

Canonical claim:

> **End-to-end selective cost depends jointly on selector complexity and specialist invocation; a lighter selector can invoke memory more often yet remain faster overall.**

HGB remains the primary scientific selector. Ridge is a deployment variant.

# 8. Narrative logic

## Act 1 — Live-room recommendation mixes ephemeral rooms with persistent relationships

A room-only model is weak; persistent streamer identity is powerful. Therefore build a streamer-heavy Dual-ID base before making any memory claim.

## Act 2 — A paradox appears under sampled-active evaluation

Always Memory is worse than Dual-ID, yet selective Memory significantly improves it. This establishes the globally-inferior-but-locally-useful regime.

## Act 3 — Show that selection targets relative utility rather than generic difficulty

Predicted relative utility stratifies realized specialist advantage. At matched budgets, utility routing beats difficulty routing. State and confidence are complementary.

## Act 4 — Expand the candidate universe

Full-active evaluation is not merely a robustness checkbox: the aggregate ordering reverses. Memory becomes globally stronger, yet a native selective gate improves over both Base and Always Memory.

This reveals **candidate-regime dependence**.

## Act 5 — Expand the temporal regime

Under strict temporal shift, Memory becomes still more broadly valuable and escalation rises to ~60–75%.

Together Acts 4–5 establish that the scientific object is the **distribution of relative utility across regimes**, not a fixed ranking between models.

## Act 6 — Position against routing/deferral literature

Learning-to-Defer is the generic lineage. DS-Frame is the closest recommendation-specific fast/slow collision. The paper's novelty is not generic routing but the explicit relationship-memory regime, identity control, candidate/temporal reversals, and predictive relative utility.

## Act 7 — Close with serving cost

Selector complexity can dominate incremental overhead; invocation rate alone is insufficient.

# 12. Statistical / scientific guardrails

Safe:

- memory-relative utility is regime-dependent;
- sampled-active Memory is globally inferior yet locally complementary;
- full-active candidate expansion reverses aggregate ordering;
- selective full-active-native routing beats both fixed choices;
- utility routing beats generic difficulty at matched budget in both candidate regimes;
- state+confidence is strongest in both regimes;
- strict temporal shift broadens Memory usefulness;
- selector complexity contributes materially to latency.

Unsafe:

- “Memory is globally inferior” without naming the regime;
- “Selective always beats Always Memory” (false in GTS);
- “well calibrated” for the HGB utility estimates;
- generic “first routing/deferral recommender” claims;
- “Selective beats DS-Frame routing”;
- calling MemoryFusion an LLM agent;
- causal GMV/conversion claims;
- direct numerical comparison to official DCGLive under incompatible protocols.
