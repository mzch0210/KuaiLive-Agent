# Introduction — reviewer-tightened draft for Knowledge-Based Systems

> **Status:** manuscript draft; not a protocol or frozen result file.

Sequential recommender systems infer users’ evolving preferences from ordered interaction histories, and self-attentive models such as SASRec and BERT4Rec established strong sequence encoders for next-item recommendation (Kang and McAuley, 2018; Sun et al., 2019). Yet stronger sequence modeling does not remove a more basic question: when does an additional source of historical evidence still contain information that is incremental relative to what the Base recommender already represents? More evidence is not necessarily more useful. An auxiliary source can be redundant when the Base already represents overlapping information, ineffective when no target-specific evidence exists, or complementary when it retains useful information outside the Base’s current representation. The relevant problem is therefore not whether more historical evidence can improve recommendation in general, but whether that evidence has positive marginal value relative to what the Base already captures.

Recent recommendation research has become increasingly sophisticated at integrating heterogeneous information. Knowledge-aware recommendation uses adaptive gating to combine collaborative, semantic, structural, and long-/short-term preference signals; multimodal sequential recommendation explicitly models complementary information while suppressing redundancy and modality noise; reliability-aware approaches further estimate the trustworthiness of content and interaction evidence; and recent sequential models also employ adaptive expert structures to improve representation quality (Sun et al., 2025; Xie et al., 2026; Zhu et al., 2026; Zhang et al., 2026; Huo et al., 2026). These studies primarily address how available evidence should be represented, denoised, weighted, aligned, or fused. This leaves a different methodological question: does a particular auxiliary evidence source contribute positive marginal value beyond a strong Base for the current recommendation event? We refer to this perspective as **Base-relative evidence valuation**. The unit of analysis is not the standalone quality of an auxiliary model, but the incremental utility of its evidence conditional on what the Base already represents.

Live-streaming recommendation provides a useful setting in which to study this question because candidate availability changes over time and repeat consumption of specific channels is substantial (Rappaz et al., 2021). KuaiLive further provides a real-time interactive benchmark with live-room timing information and multiple forms of user–streamer interaction, enabling evaluation under dynamic live-streaming conditions (Qu et al., 2026). We therefore use an explicit relationship-memory specialist as a transparent source of persistent user–creator evidence. For a target creator, this evidence can occupy three Base-relative analysis states: **represented**, when the target relationship appears in the Base-visible sequence; **recoverable but unrepresented**, when it exists only in older history; or **unavailable**, when no previous target-specific relationship exists. These states are not assumed to determine specialist utility by themselves. Rather, they describe how the specialist’s evidence relates to the current Base representation.

Our empirical results show why this Base-relative distinction matters. On KuaiLive, the aggregate ordering between relationship Memory and a strong Base reverses across candidate regimes even when the evaluated events and evidence-state composition are unchanged, indicating that regime dependence cannot be reduced to state prevalence alone. On Twitch/LiveRec, frozen DEV analysis identifies strong conditional heterogeneity across the three evidence states, and the same sign structure reproduces on untouched TEST. More importantly, a DEV-only context-length intervention holds canonical relationship Memory fixed while expanding the Base context from 8 to 16 and from 16 to 32 interactions. For the same events that move from recoverable-but-unrepresented to represented as the Base context expands, specialist-minus-base utility falls by approximately 0.42–0.45 NDCG@10. This provides interventional support for a Base-relative visibility interpretation: the same persistent evidence becomes markedly less valuable once the Base representation comes to include it. The result does not imply a universal causal law, because operating regime and finer recency structure also affect realized utility.

This heterogeneity leads naturally to a selective decision problem. Let \(B\) denote the Base recommender and \(M\) the relationship-memory specialist, and define event-level specialist-minus-base utility as

\[
\Delta_m(x)=u(M,x)-u(B,x).
\]

Selective specialist use should therefore target the expected marginal value of \(\Delta_m(x)\), rather than simply identifying where the Base is weak. This distinction is substantive: Base difficulty identifies hard events, whereas specialist-relative utility identifies events that this particular evidence source can improve. A difficult event may still contain no target-specific evidence recoverable by the relationship specialist. In our matched-budget analysis, utility-based selection is more strongly concentrated on recoverable-but-unrepresented events, whereas a generic Difficulty control disproportionately selects unavailable events. Generic expert assignment and Learning-to-Defer already provide established formulations for allocating instances among predictors or experts under accuracy and cost trade-offs (Mao et al., 2025). Our aim is therefore not to introduce a new general deferral or gating theory, but to characterize and exploit the structured conditional utility of a transparent relationship-evidence specialist in recommendation.

This work makes three main contributions. First, we formulate **Base-relative evidence valuation** for recommendation by evaluating a transparent auxiliary relationship-evidence source through event-level marginal ranking utility relative to a strong Base, rather than through standalone specialist performance or Base difficulty alone. Second, we provide an interpretable characterization of represented, recoverable-but-unrepresented, and unavailable relationship evidence, combine frozen DEV-to-TEST replication with a Base-context intervention, and show that the marginal value of the same persistent evidence contracts sharply once the Base comes to represent it; KuaiLive regime decomposition further shows that evidence state structures but does not deterministically fix utility. Third, we connect this mechanism to selective specialist use and evaluate it across recommendation regimes, strong Base controls, independent training seeds, and a frozen second-platform test. On untouched Twitch/LiveRec TEST, Selective Utility improves NDCG@10 by 0.00772 over the Base and by 0.00644 over an exact-budget Difficulty control. Taken together, the results support a view of auxiliary recommendation evidence as **Base-relative rather than intrinsically valuable**: whether persistent historical evidence is worth using depends on what the Base already represents and on the operating recommendation regime.
